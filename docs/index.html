What Gets Installed

Everything needed for fast, comfortable .NET development inside WSL — zero bloat, safe to re-run.

📦

Nala Package Manager

Installs Nala first and uses it for parallel, readable APT downloads — plus adds an interactive apt / sudo apt wrapper.

nala apt wrapper nala fetch
⚡

.NET SDK & Global Tools

Uses Microsoft's official dotnet-install.sh to avoid Ubuntu/Microsoft APT conflicts, with native Linux runtime deps and EF Core CLI.

dotnet dotnet-ef dotnet-outdated libicu-dev
🌿

Git & GitHub Workflow

Full Git toolchain with GitHub CLI, Lazygit TUI, Git LFS, and WSL-safe defaults (core.autocrlf=input) without clobbering existing config.

git git-lfs gh lazygit
📊

System & Monitoring

Instant system overview and live resource monitoring tailored for WSL terminals, with automatic GitHub .deb fallback for fastfetch.

fastfetch btop htop ncdu
🛠️

Modern CLI Utilities

Everyday terminal upgrades with automatic bat and fd symlinks in ~/.local/bin and smart directory jumping.

bat ripgrep fd fzf zoxide eza jq tmux
🔁

Idempotent Shell Profile

Updates ~/.bashrc (and ~/.zshrc if present) inside a clean managed block — re-run anytime without duplicate lines.

DOTNET_ROOT ff / lg aliases starship (opt)

Post-Install Quick Steps

After the script finishes, run these to complete your setup:

STEP 1

Reload your shell

source ~/.bashrc
STEP 2

Pick fastest APT mirrors

sudo nala fetch
STEP 3

Sign in to GitHub

gh auth login
STEP 4

Verify .NET & system

dotnet --info && fastfetch
